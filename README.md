# 文件整理

整理電腦上文件的 Windows 桌面程式（.NET 10 WPF）。資料夾就是硬碟上真正的資料夾，在程式裡建的資料夾、放進來的文件，用檔案總管打開也看得到一樣的結構。

## 下載

- **APP 啟動器**：在啟動器裡找到「文件整理」，按「下載」後開啟。有新版時啟動器會標示「可更新」。
- **自己安裝**：到 [Releases](https://github.com/asdZzz-coder/document/releases/latest) 下載 `DocumentKeeper-ClickOnce.zip`，解壓縮後執行「安裝.cmd」。開始功能表與桌面會有「文件整理」捷徑，之後開啟程式時會詢問是否更新。

不需要另外安裝 .NET（已內建執行環境）。

## 功能

- **資料夾**：左側樹狀清單，可以一層一層往下建立子資料夾。「新增資料夾」會建在目前選的資料夾裡；滑過資料夾（或按右鍵）可以「新增子資料夾 / 重新命名 / 刪除」；雙擊可展開或收合
- **存放位置**：右上角「存放位置」（或左下角的筆）可以改成任何資料夾，例如 D 槽或隨身碟。原本的位置有東西時，可以選擇全部搬到新位置，或直接改用新位置。預設是「文件\文件整理」
- **加入文件**：按「加入文件」選檔案，或從檔案總管把檔案（或整個資料夾）拖進中間的清單，會**複製**到目前的資料夾，原本的檔案不動；撞名時自動加上 (2)、(3)
- **整理**：把文件拖到左邊的資料夾就會搬過去，資料夾也可以拖進別的資料夾；也可以用右側的「移到…」
- **全部文件**：左上角「全部文件」列出所有資料夾裡的文件，並標示每份文件在哪個資料夾
- **搜尋**：搜尋目前資料夾（含子資料夾）裡的檔名與資料夾名稱；可以依名稱、修改日期、大小、類型排序
- **文件資訊**：右側顯示位置、大小、修改與建立日期，可以開啟、在檔案總管顯示、重新命名、刪除
- **刪除**一律丟到資源回收筒，刪錯了可以還原
- 快速鍵：雙擊或 Enter 開啟、F2 改名、Delete 刪除
- 在檔案總管裡改了檔案，程式會自動更新畫面
- 淺色 / 深色 / 跟隨系統主題

設定（存放位置、主題）存在 `%AppData%\DocumentKeeper`；文件本身都在存放位置裡。

## 開發

```bash
dotnet build document/document.csproj
dotnet test document.Tests/document.Tests.csproj
```

### 發佈新版

推送 `v` 開頭的標籤後，GitHub Actions 會先跑測試，再用 ClickOnce 打包並上傳到 Releases，APP 啟動器就會看到新版本：

```bash
git tag v1.0.1
git push origin v1.0.1
```
